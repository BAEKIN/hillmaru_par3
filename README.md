# 힐마루 파3 (Hillmaru Par3)

힐마루 골프앤리조트 포천의 디자인을 참고한 파3 골프클럽 예약 홈페이지입니다.

## 미리보기

로컬에서 정적 파일 서버로 실행합니다.

```bash
python3 -m http.server 8420
```

브라우저에서 `http://localhost:8420` 접속.

## 구성

```
index.html      메인 페이지
css/style.css   스타일 (크림 & 딥그린 톤)
js/main.js      히어로 슬라이더, 모바일 메뉴, 예약 폼 로직
images/         이미지 리소스
```

## 페이지 구성

- **헤더** — 스크롤에 따라 배경이 전환되는 반투명 헤더, 모바일 햄버거 메뉴
- **히어로** — 풀스크린 이미지 슬라이더 + 메인 카피
- **공지 바** — 그린피 특가 등 안내 문구
- **코스 소개** — 홀 구간별 카드 소개
- **예약 폼** — 날짜/시간/인원/예약자 정보 입력, 클라이언트 검증, 신청 완료 모달

## 기술 스택

순수 HTML / CSS / JavaScript (프레임워크 없음)
